大模型凭什么能写会算，如何从结构原理训练机制拆开看

发表于2026-10-10|更新于2026-10-28
|AILLM
|浏览量:

概述：四层心智模型

大语言模型（LLM）常被神化为"涌现智能的黑盒"，但拆开看，它是一套层次分明的工程体系。理解大模型只需回答四个问题：

层面 关键问题 一句话答案
模型结构 它由什么搭成 Transformer：注意力负责"看上下文"，前馈网络负责"算与记"
运行原理 它靠什么成立 海量参数 + 预测下一个词，配合 Scaling Law 把续写逼近理解
训练流程 它是怎么练成的 预训练学知识 → 监督微调学对话 → 偏好对齐学分寸
工程机制 它跑起来靠什么 KV Cache、稀疏激活、位置编码外推、采样控制等一套运行时机制

四层自底向上依赖：结构是地基，原理是物理定律，训练是把知识压进地基的过程，机制是让庞然大物高效服务的工程艺术。先看一张全景图：

flowchart LR
    A[万亿词元语料] --> B[预训练<br/>Next Token Prediction]
    B --> C[基座模型<br/>会续写不会对话]
    C --> D[监督微调 SFT<br/>学指令格式]
    D --> E[对话模型<br/>会回答答得糙]
    E --> F[偏好对齐 RLHF/DPO<br/>学人类价值观]
    F --> G[助手模型<br/>答得得体]
    G --> H[推理服务<br/>KV Cache/量化/流式输出]
    H --> I[上层应用<br/>RAG/Agent/工具调用]

第一部分 模型结构：Transformer 骨架

1.1 为什么是 Transformer

在 Transformer（2017, 《Attention is All You Need》）之前，文本建模由 RNN/LSTM 主导，它们逐词串行处理，有两个致命缺陷：无法并行，以及长距离信息衰减（一句话开头的线索传到句尾早已"失忆"）。

Transformer 的核心变革是自注意力（Self-Attention）：序列中任意两个词直接建立连接。两个决定性优势——所有词元可并行计算，吃满 GPU；任意距离的依赖都是 O(1) 直连。大模型能"吞"下整本书、整份代码库，根基就在这里。

主流大模型（GPT、LLaMA、Qwen、Claude 等）都采用 Decoder-only 结构，一个 Transformer 块由"注意力子层 + 前馈子层"堆叠而成，数据流如下：

flowchart TB
    T0[输入词元序列] --> TE[词元嵌入 Token Embedding]
    TE --> TR[Transformer 块 重复 N 次]
    subgraph BLK[块内数据流]
        RA[带因果掩码的自注意力] --> RN[残差连接 + 归一化]
        RN --> RF[前馈网络 FFN] --> RN2[残差连接 + 归一化]
    end
    TR --> BLK
    BLK --> LH[最终隐藏层向量]
    LH --> LO[输出投影层<br/>映射到词表维度]
    LO --> LS[Softmax 概率分布]
    LS --> TN[采样得到下一个词]
    TN -.回填输入.-> T0

以一个典型 8B 模型（LLaMA-3-8B 规格）为例，各组件的角色和规模：

组件 作用 规格示例
词元嵌入 把离散词 ID 变成连续向量 128,256 词表 x 4,096 维
位置编码 注入词序信息（RoPE） 每层作用于 Q、K
自注意力 词与词互相交换上下文信息 32 个头，GQA 共享 8 组 KV
前馈网络 逐词独立的非线性变换（SwiGLU） 4,096 → 14,336 → 4,096
残差 + RMSNorm 稳定训练、防止梯度消失 每个子层各一组
输出投影 隐藏向量 → 词表 logits 与嵌入层权重绑定

值得注意的参数分布事实：FFN 参数量约是注意力的 2 倍（约占块内总参数 2/3），且嵌入层与输出层共享权重。这暗示了后面的分工——注意力管"读"，FFN 管"记"。

1.2 词元与嵌入：离散世界的连续化接口

模型不认识"字"，只认识词元（Token）：文本切分后的最小建模单位，介于"字"和"词"之间，tokenization 可能被切成 token + ization，代码空格缩进也占词元。

切分由 BPE 类子词算法完成：从单字符出发，反复合并语料中最高频的相邻符号对，直到达到目标词表规模（通常 3 万～20 万）。词元是模型世界的原子——计费、上下文长度限制、能力边界（如数不对 strawberry 里有几个 r）都源于此。

嵌入层是一张可学习的大表：把每个词元 ID 映射为几千维向量。其意义不在单点，而在空间关系——语义相近的词向量距离近，king - man + woman ≈ queen 这类类比关系几乎线性可测。语义，在这里第一次变成了几何。

1.3 自注意力：大模型的"理解"引擎

注意力机制的直觉是一个软性查表：每个词带着"疑问"去问全句"谁跟我有关"，相关者的信息按比例取回。形式上，每个词的嵌入经三个可学习矩阵投影为三种角色：

  • Query（查询）：我正在找什么信息；

  • Key（键）：我能提供什么信息的"标签"；

  • Value（值）：真正被取回的信息本体。

$$
\mathrm{Attention}(Q,K,V)=\mathrm{softmax}!\left(\frac{QK^{T}}{\sqrt{d_k}}\right)V
$$

三个细节各有必然性：

  1. $QK^T$ 点积：衡量"查询和标签有多匹配"，得到注意力权重矩阵；

  2. $\sqrt{d_k}$ 缩放：维度越高点积越大，softmax 会饱和成"非 0 即 1"的硬选择导致梯度消失，除以 $\sqrt{d_k}$ 把方差拉回 1；

  3. Softmax 归一化：把分数变成和为 1 的权重，输出是 Value 的加权平均。

在 Decoder-only 模型中还要叠加因果掩码（Causal Mask）：把"未来位置"的权重置为 $-\infty$，确保每个词只能看见自己和左侧历史——既不许作弊看答案，也天然兼容自回归推理。

注意力的计算复杂度随序列长度呈 $O(n^2)$——这是上下文窗口成本的根源，也是 FlashAttention、线性注意力等一大片优化技术的靶心。

1.4 多头注意力：一个"头"只看一种关系

单个注意力层的输出是一次加权平均，倾向把信息"抹匀"。**多头（Multi-Head）**把 Q/K/V 投影到多个低维子空间并行计算：32 个头、每头 128 维，等于 32 组独立的"提问-检索"并行进行。

训练后分析注意力权重可以发现，不同的头自发分化出功能：有的追踪指代（"它"指向谁），有的聚焦邻近词，有的跨长距离搬运关键信息——多头等于一支分工明确的关注团队。现代大模型进一步用 GQA（分组查询注意力） 让多个 Query 头共享一组 KV，用少量表达力换取推理显存大幅下降。

1.5 前馈网络：真正"存储知识"的地方

如果说注意力是"信息的搬运工"，FFN 才是"知识的仓库"。FFN 对每个词独立做两层非线性变换，典型结构是"升维 4 倍→激活→降回原维"：

flowchart LR
    X[输入向量 x<br/>4096 维] --> P1[上投影矩阵]
    P1 --> H[隐藏层<br/>14336 维]
    H --> G[SwiGLU 门控激活]
    G --> P2[下投影矩阵]
    P2 --> Y[输出向量<br/>4096 维]

为什么知识存在这里而非注意力？机械可解释性研究发现，单个神经元/低秩子空间承载可定位的实体知识（著名的"金门大桥神经元"），抑制它模型就会忘记对应事实；而假说**“注意力是钥匙，FFN 是记忆”**给出了解释：注意力把"巴黎"相关信息汇聚到当前位置，FFN 将其变换为"法国"的输出预测，本质是一次键值回忆。约 2/3 的参数在 FFN，知识容量主要就在 FFN。

现代模型用 SwiGLU 变体：上投影后加一路门控分支逐元素相乘，相当于给每个维度装"音量旋钮"，表达力更强。

1.6 残差连接与归一化：让百层深塔不塌

Transformer 块动辄 32～126 层深，没有两个稳定器根本训不动：

  • 残差连接（$y = x + F(x)$）：输出叠加回输入，为梯度提供直达底层的"高速公路"，某层学坏了也只是"没加成"而非"全崩掉"；残差流还是注意力和 FFN 交换信息的公共总线；

  • 归一化：现代模型用 Pre-Norm + RMSNorm——子层前先归一化，比 LayerNorm 少一半计算；Pre-Norm 让梯度范数随深度不衰减，是数百层训练可行的前提。

1.7 位置编码：给"无序"的注意力注入时间轴

注意力本身是置换不变的——打乱词序，输出不变：“猫抓老鼠"和"老鼠抓猫"必须不同，所以位置编码要给每个词盖上"时间戳”。演进路径：

方案 思路 代表 局限
绝对正弦编码 用不同频率的sin/cos给每个位置造唯一指纹，加进嵌入 原始 Transformer 外推能力差
学习式位置嵌入 位置当作可学习参数 GPT-2/3 超出训练长度即失效
ALiBi 不打标签，直接在注意力分数上按距离加线性惩罚 BLOOM 距离偏好过于刚性
RoPE 旋转编码 按位置把 Q、K 向量旋转一个与位置成比例的角度，点积自动只依赖相对距离 LLaMA、Qwen、几乎所有新模型 长距离角度分辨力衰减

RoPE 是当代事实标准：位置 $m$ 的词向量被旋转 $m\theta$，两词点积只与相对距离 $m-n$ 有关，"距离越远注意力天然越弱"恰好是需要的归纳偏置；离散位置变成连续角度后，YaRN 等外推技术按比例缩放角度即可把 8K 模型扩到 128K。

1.8 输出层：从向量到词

序列走完 N 层后，取最后一个位置的隐藏向量（因果掩码保证它浓缩了全部历史），乘上输出投影（与嵌入表转置共享），得到整个词表的 logits，softmax 转为概率：

这个"取最后一位、预测下一位"的循环就是自回归（Autoregressive）：每步只输出一个词元的概率分布，采样结果拼回输入再算下一步。正是这个循环乘以万亿参数与万亿数据，涌现出下文的一切。

第二部分 运行原理：预测下一个词为何够用

2.1 一个目标为什么能装下所有能力

大模型的训练目标只有一个：Next Token Prediction——给定前文，最大化真实下一个词的概率。损失函数是交叉熵：

$$
\mathcal{L}=-\sum_{t}\log P\left(x_{t} \mid x_{1 \dots t-1}\right)
$$

即"模型分配给正确答案的概率"取负对数——预测越准，损失越低。为什么简单目标能逼出翻译、推理、写代码的能力？因为要预测得足够好，模型必须隐式地理解世界：

  • 要接对"法国首都的标志性建筑是__"，要么记住实体知识，要么学会类比迁移；

  • 要续写对一段代码，必须隐式掌握语法规则和函数语义；

  • 要接好一段翻译，等价于学到了双语对齐分布——翻译是压缩的副产品。

续写、问答、翻译、解题，在词元层面都是同一分布的不同切片。压缩与预测在此等价：足够好的预测器必然是理解器——这是大模型的第一性原理。

2.2 Scaling Law：容量换智能的物理定律

Kaplan（2020）与 Chinchilla（Hoffmann, 2022）先后给出了经验规律：模型损失随参数量 $N$、数据量 $D$、算力 $C$ 呈幂律下降，其中参数与数据必须均衡放大——

$$
L(N, D) \approx E + \frac{A}{N^{\alpha}} + \frac{B}{D^{\beta}}, \qquad \alpha \approx \beta \approx 0.34,\quad N_{\mathrm{opt}}😄_{\mathrm{opt}} \approx 1:20
$$

Chinchilla 推翻了"参数越大越好"：70B 模型喂 1.4T 词元，胜过 175B 只喂 300B 词元的 GPT-3——每个参数至少"吃" 20 个词元才不浪费。

而当代模型（LLaMA-3-8B 用 15T 词元，每参数远超 20 倍）刻意严重过训练：牺牲训练算力换小模型高性能，为的是推理便宜。这条定律把"炼丹"变成可规划的工程；粗略估算训练 FLOPs $\approx 6ND$，8B 模型 × 15T 词元 ≈ $1.8\times10^{24}$ FLOPs，正对应数百张旗舰 GPU 训练数十天。

2.3 知识如何被"压"进参数

训练完成的模型，其知识以三种粒度分布在权重里：

  1. 事实知识——存于 FFN 的键值结构（注意力取回模式 → FFN 完成变换），如"罗马在意大利"；

  2. 技能知识——分布在跨层电路（circuit）中，如指代消解、归纳模式（induction head：见过"A是B"，就能对"C是__"补出 B）；

  3. 风格与格式——浅层注意力和输出头即可承载，这也是 SFT 只需少量数据的原因。

理解这一分层，才能理解后文的幻觉（检索失败而非存储失败）、微调（改的是分布而非"注入新知识"）与 RAG（外挂检索弥补参数记忆的模糊性）。

2.4 能力边界：它做不到什么

原理同时决定了缺陷：

  • 知识冻结在训练截止日，不会自己更新；

  • 概率输出不保证事实——它优化的是"像"，不是"真"；

  • 算术、精确检索、计数非其所长，词元化甚至让它数不清字母；

  • 没有内部状态机，"记忆"全靠上下文窗口携带。

这四点分别由幻觉治理、RAG、外部计算、Agent 记忆机制补救，见第四、五部分。

第三部分 训练流程：三阶段铸模

从基座模型到可用助手要走完三段路：

flowchart LR
    A[阶段 A 预训练<br/>万亿词元自监督] --> B[基座模型<br/>懂万物但不服管教]
    B --> C[阶段 B 监督微调<br/>数万至数十万指令对]
    C --> D[对话模型<br/>会答题但看人下菜]
    D --> E[阶段 C 偏好对齐<br/>RLHF 或 DPO]
    E --> F[助手模型<br/>知进退懂分寸]
    E -.蒸馏与量化.-> F2[小模型与端侧版本]

3.1 阶段 A 预训练：从随机噪声到世界模型

起点是所有权重随机初始化，数据是去重过滤后的数万亿词元（网页、书籍、代码、论文）。训练就是 2.1 节那个唯一目标的十亿亿次重复。工程上值得了解的关键点：

  • 并行策略：单卡显存装不下一个模型的梯度+优化器状态，需要 TP（张量并行）+ PP（流水线并行）+ DP/ZeRO（切开数据与优化器状态）组合成 3D/4D 并行，横跨数千张卡；

  • 吞吐细节：混合精度（BF16）+ 梯度检查点 + FlashAttention，每个百分点的 MFU（有效算力利用率）都是真金白银；

  • 不稳定处理：loss spike 随时可能出现，靠梯度裁剪、warmup 重启、甚至回滚早期 checkpoint 重训一段。

预训练完成得到基座模型，它满腹经纶却只会续写：你问"怎么煮溏心蛋？“，它可能回”？这是一个常见问题。煮溏心蛋的方法如下……“——它没学过"被问就要答”。

3.2 阶段 B 监督微调（SFT）：教会模型"对话"这个文体

修复方法：用高质量的指令-回答对（几万到几十万条，人类撰写或强模型蒸馏）继续训练，目标仍是预测下一个词，但只算回答部分的损失：

flowchart TB
    A[词元序列 = 指令 + 回答] --> B[模型照常前向计算]
    B --> C{逐词元计算交叉熵?}
    C -- 指令部分 --> D[损失乘 0<br/>只作为上下文]
    C -- 回答部分 --> E[损失计入反传<br/>学习如何作答]

SFT 教会三件事：问答范式、输出格式（分点、代码块、语气）、以及"不知道就说不知道"的行为模板。微调家族里的 LoRA/QLoRA 是低成本变体：冻结原权重，只训练旁路低秩矩阵，单卡即可给 7B 模型"加技能"。

SFT 的天花板也明显：答案"好不好"没有梯度信号——模型能学会答题格式，却学不会"面对危险请求要拒绝"“长篇大论不如一句点睛”。分寸感，需要第三阶段。

3.3 阶段 C 偏好对齐：把"有用、诚实、无害"变成优化目标

RLHF（来自人类反馈的强化学习）是经典三步：

flowchart TB
    A[1 同一问题采样多个回答] --> B[2 人类两两标注偏好<br/>A比B好]
    B --> C[训练奖励模型 RM<br/>学会给任意回答打分]
    C --> D[3 PPO 强化学习<br/>策略模型最大化RM分数]
    D --> E[KL约束锚定SFT模型<br/>防止讨好奖励模型而失真]
    E --> F[对齐后的最终模型]

思想是把"人类口味"蒸馏成一个可微的奖励函数，再用 RL 优化。这套流程有效但笨重：要同时维护策略、参考、奖励、价值 4 个模型，训练成本高且易崩溃。

DPO（直接偏好优化，2023）是重要简化：可以证明 RLHF 的最优解等价于一个用偏好对直接构造的对比损失——让被偏好的回答比未被偏好的回答概率更高即可，不需要奖励模型、不需要 RL 循环：

$$
\mathcal{L}{\mathrm{DPO}}=-\log\sigma!\left(\beta\left[\log\frac{\pi\theta(y_w|x)}{\pi_{\mathrm{ref}}(y_w|x)}-\log\frac{\pi_\theta(y_l|x)}{\pi_{\mathrm{ref}}(y_l|x)}\right]\right)
$$

因为训练廉价、效果稳定，DPO 及其变体成为许多开源模型的对齐首选。而 GRPO（DeepSeek 推广）走另一条路：取消价值网络，用同一问题一组采样的相对得分（数学、代码等可验证场景直接用正确性打分）作为优势估计。

对齐之外还有一组安全机制：输入侧提示注入过滤、输出侧分类器审查等，统称护栏（Guardrails）——对齐改变模型的"性格分布"，护栏是部署时再加的外挂保险。

3.4 高效架构训练：MoE 与长上下文扩展

训练阶段还要解决两个"大"问题：

MoE（混合专家）：稠密模型每个词元都激活全部参数，成本随总参数线性涨。MoE 把 FFN 换成 K 个"专家"并联，路由器每个词元只选少数专家计算：

flowchart LR
    X[输入词元] --> R[可学习路由器<br/>打分并取 TopK]
    R --> E1[专家 1]
    R --> E2[专家 2]
    R --> Ek[... 其余专家<br/>未被选中则不计算]
    E1 --> M[按路由权重加权合并]
    E2 --> M
    Ek --> M
    M --> Y[输出 + 辅助负载均衡损失<br/>防止专家旱涝不均]

总参数巨大（存储容量大）、激活参数小（计算和显存便宜）：Mixtral 8x7B 总参 47B 每词元仅激活 13B；DeepSeek-V3 总参 671B 激活 37B。代价是路由训练不稳定与负载均衡的辅助损失设计。

长上下文扩展：预训练序列通常只有 4k-8k（$O(n^2)$ 注意力太贵），发布前要扩到 128k。配方是：RoPE 基频放大 + YaRN 类角度插值 + 少量长文本继续训练。

3.5 蒸馏与后训练生态

强模型产出的回答可以被弱模型模仿（蒸馏），推理模型的"思考链"同样可蒸馏进小模型；加上量化，构成"训练一次、随处部署"的成本梯度。现代流水线在 SFT/RLHF 之后还常接一个 Reasoning RL 阶段（可验证奖励的强化学习），这正是 R1 类推理模型"思考能力"的来源。

第四部分 工程机制：推理时模型如何工作

训练解决"能力从哪来"，机制解决"服务怎么跑"。

4.1 KV Cache：自回归的必然后果与成本大头

朴素自回归生成每步都要重算整个前文，总计算 $O(N^3)$。但因果注意力有个关键性质——历史词元的 K、V 永远不会因新词加入而改变（它们看不见未来）。

于是可以缓存：每生成一步，只算新词元的 Q/K/V，把 K/V 追加进缓存，新 Query 与全部历史 K/V 做注意力：

flowchart LR
    A[生成第 N 个词] --> B[仅计算第 N 个词元的 Q K V]
    B --> C[KV Cache 追加新的 K V]
    C --> D[新 Q 对上 N 全部 K 做注意力<br/>历史部分零重算]
    D --> E[输出第 N 个词]
    E --> A

计算量降到 $O(N^2)$，首词元之后的每步延迟接近常数。代价是显存：每层每词元都要存一对 K/V。以 8B 模型（32 层 × GQA 8 头 × 128 维，BF16）为例，每千词元 KV Cache 约占 128MB 显存——高并发服务里，KV Cache 而非模型权重才是显存第一大户。围绕它的优化军队：

  • PagedAttention/vLLM：像操作系统管内存分页一样管理 KV Cache，消除碎片；

  • MQA/GQA：共享 KV 头，缓存直接缩小 4～8 倍；

  • 滑动窗口/驱逐策略：只保留近处+关键词元的 KV；

  • 前缀缓存（Prefix Cache）：多个请求共享同一段 system prompt 的 KV，不必重算。

4.2 Prefill 与 Decode：一次请求的两个世界

带 KV Cache 后，一次推理天然分成两个性能特征迥异的阶段：

  • Prefill：并行处理整个输入提示，建好初始 KV Cache——计算密集（算力瓶颈）；

  • Decode：逐词元生成，每步只有一个小向量的计算却要读写全部 KV——访存密集（带宽瓶颈）。

这个划分解释了大量现象：长输入贵（prefill 算力）、流式输出"一个字一个字蹦"（decode 逐词元）、连续批处理能大幅提升吞吐（decode 时 GPU 大量空转，正好填满）。量化、投机解码（小模型草拟+大模型验证）都是给 decode 提速的机制。

4.3 上下文窗口：注意力的"工作记忆"及其衰减

上下文窗口是模型一次推理能"看见"的全部词元，等价于工作记忆：窗口内可被即时调用，窗口外一概失忆。但 RoPE 外推"支持"长窗口不等于"用好"：

  • Lost in the middle：关键信息放在长上下文中部时，检索准确率显著下降，开头和结尾才是"黄金展位"；

  • 有效长度 < 标称长度：标称 128k 的模型，对 64k 处细节的召回可能已明显打折；

  • 成本与延迟：注意力 $O(n^2)$ 与 KV Cache 线性显存，长上下文两头都贵。

工程对策：最重要指令放开头、关键约束在结尾复述、超长内容走 RAG 按需召回而不是整篇塞入。这也解释了为什么提示词的位置和长度同样重要。

4.4 采样策略：同一个模型，七种性格

模型每步输出的是概率分布，从分布里怎么选，决定输出性格。常用三个旋钮：

配置 效果 适用
temperature = 0 每步取最大概率（贪心） 事实问答、代码抽取、需要可复现
T = 0.7, top-p = 0.8 轻度随机，兼顾稳定与流畅 通用对话
T = 1.2, top-p = 0.95 分布被"抹平"，措辞跳跃 头脑风暴、创意写作
top-k = 50 只在概率前 50 名里抽 防止长尾离谱词

温度在 softmax 前给 logits 除以 T：T 越小分布越"尖"（赢者通吃），越大越"平"（人人有机会）。多轮对话会放大幻觉也源于此：每步采样的微小随机偏移沿自回归链条累积。另一个事实：同一问题不同措辞、few-shot 顺序都会导致结果波动——这是提示工程成为"工程"的原因。

4.5 思维链机制：把推理"摊开在纸面上"

模型单次前向的深度是固定的（层数），复杂推理一步登天做不到。思维链（CoT）的本质是把一次不可能的一跳，拆成很多次可行的小跳：每生成一个推理词元都追加进上下文，成为下一步计算的输入——纸笔即外置算力。"Let’s think step by step"之所以有效，是因为它触发了训练分布中"逐步解答"的模式，让模型自愿把中间步骤采样出来参与后续计算。

推理模型（o1/R1 类）把这一机制内化：后训练阶段用可验证奖励做强化学习，模型学会自发生成思考词元，并在思考中学会回溯与自我核查。代价也透明：思考词元同样计费、同样占用上下文窗口。

4.6 系统提示、指令遵循与角色机制

为什么 system prompt 影响巨大？SFT 与对齐把"指令-响应"分布刻进了模型：对话模板的角色分隔符是强信号，模型见到"system"位置的内容就落入"应当服从的规范"这一条件分布。这是训练分布使然，而非运行时真有权限校验——越狱的存在正源于此：注入攻击用措辞把分布扳到"角色扮演"分支，绕开服从路径。

第五部分 能力扩展：从模型到应用

结构、原理、训练、机制四层拼出完整的"模型"，而上层的"系统"还差三块拼图：

5.1 幻觉：概率本质与检索模糊的必然产物

幻觉根源可定位到两层：训练目标只奖励"像续写"不惩罚"编造"；推理时输出是模糊检索的最近邻——若"法国首都的标志性建筑是__“检索置信度低，模型仍会流畅地"补一个最像的”，而不是坦白不知道。幻觉率随话题长尾程度上升，随采样温度与对话轮数放大。

治理与机制一一对应：降温/强制引用（采样层）、RAG 提供权威上下文（检索层）、奖励"我不知道"（对齐层）、工具调用外置计算（工具层）、自我核查（CoT 层）。概率生成范式内无法根除幻觉，工程目标是压到业务可接受并让关键场景可溯源。

5.2 RAG：给冻结的参数知识接上活水

知识截止问题的正面解法。检索增强的本质是把"参数化记忆"换成"非参数化记忆"：

flowchart LR
    Q[用户问题] --> R1[向量化 + 混合检索<br/>ES/Milvus/向量库]
    R1 --> R2[重排序 取TopK文档块]
    R2 --> P[拼装提示<br/>问题 + 权威上下文]
    Q --> P
    P --> M[大模型基于上下文作答<br/>并要求引用出处]
    M --> A[带来源的答案]

模型从"凭记忆答题"变成"开卷考试"，知识可实时更新、答案可溯源。代价是检索质量成为新瓶颈——召回不准，生成必错，所以生产级 RAG 的核心工作量其实在检索侧。

5.3 工具调用与 Agent：把"下一步"的决策权交还循环

Function Calling 的训练来源是 SFT 阶段注入的"调用格式-执行结果-继续作答"样本：模型学会在需要时输出结构化调用意图而非直接回答，运行时系统执行工具、把结果作为新词元回填上下文，循环继续。这恰好利用了自回归的本性——一切外部能力，最终都以"文本进、文本出"的方式编织进同一个预测循环。

Agent = 循环 + 规划提示 + 工具集 + 记忆机制（短期靠上下文窗口，长期靠外部存储回注）。思考→行动→观察→再思考的 ReAct 环路，本质上仍是 4.5 节"把推理摊在纸面上"的扩展：摊开的不只是思路，还有与真实世界的每一次交互。

    subgraph S1[结构层]
        A1[Transformer = 注意力搬运 + FFN存储<br/>残差归一化维持深度 + RoPE注入词序]
    end
    subgraph S2[原理层]
        A2[预测下一个词 + Scaling Law<br/>压缩即理解 容量换智能]

        A3[预训练学知识 → SFT学对话 → 对齐学分寸<br/>MoE扩容 + 长上下文扩展]
    end

    end

最后用五组常见"误解 → 事实"收束全文，也作为自检清单：

流行误解 技术事实
模型"理解"了语言 它在优化下一个词分布，理解是压缩的副产品
参数越大越聪明 Chinchilla 定律：参数与数据须均衡，过训练换推理性价比更常见
注意力是知识的仓库 事实知识主体在 FFN，注意力负责检索搬运
上下文窗口越长越好用 lost-in-the-middle + $O(n^2)$ 成本，有效长度常远低于标称
幻觉=模型坏了 概率生成+模糊检索的固有产物，只能治理不能根除

大模型没有魔法：结构上是注意力与矩阵乘法的反复堆叠，原理上是 Scaling Law 加持的续写目标，训练上是三段各有分工的数据投喂，机制上是让庞然大物跑得省、答得稳的工程艺术。想清四层各自的"为什么"，面对任何新模型、新优化，你都能问出正确的问题：它改的是哪一层？
