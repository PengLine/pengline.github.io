Hexo + Butterfly 动态切换护眼模式

发表于2025-08-15|更新于2025-08-15
|ToolsHexo
|浏览量:

注意版本：框架 Hexo 7.3.0|主题 Butterfly 5.4.3

护眼模式实现原理

Butterfly 的护眼/夜间模式本质上是CSS 变量换肤 + 状态持久化。

  • CSS 变量：主题色、背景色、文字色等通过 :root 与 [data-theme="dark"] 作用域定义，例如 --card-bg、--font-color；

  • data-theme 属性：切换时修改 <html> 或 <body> 的 data-theme 属性，浏览器立即应用对应变量；

  • localStorage 持久化：通过 btf.saveToLocal.set('theme', ...) 把用户选择写入本地存储，下次打开页面时恢复；

  • 动画遮罩：Cuteen_DarkSky 与 Cuteen_DarkPlanet 是全屏渐变遮罩元素，利用 CSS 动画模拟日夜切换的视觉效果。

sequenceDiagram

动画效果技术拆解

CuteenPlanetMove 旋转动画

Cuteen_DarkPlanet 元素通过无限旋转模拟星球从地平线升起的视觉过渡。关键参数如下：

  • transform-origin: center bottom：旋转轴心设在元素底部中心，产生从地面升起的透视效果；

  • cubic-bezier(0.7, 0, 0, 1)：缓动曲线先慢后快再慢（ease-in-out 的近似变体），与渐变遮罩的淡入形成协调节奏；

  • @keyframes CuteenPlanetMove：从 rotate(0) 到 rotate(360deg) 完成一整圈。配合 width: 200% / height: 200% 确保旋转过程中星球始终覆盖视口。

渐变遮罩叠加原理

.DarkMode .Cuteen_DarkSky:before 在切换时通过 opacity: 0 → 1 的过渡实现颜色渐变：

  • 初始状态（:before）的背景为冷色调渐变 #4c3f6d → #6c62bb → #93b1ed，但 opacity: 0 不可见；

  • 元素自身 .Cuteen_DarkSky 的背景为暖色调 #feb8b0 → #fef9db，始终可见；

  • 切换瞬间为 .DarkMode 添加 :before 的 opacity: 1，冷色覆盖暖色，配合星球旋转完成“日落→夜晚”的视觉过渡；

  • 切换完成后（约 2s）通过 transition: opacity 3s 将遮罩淡出移除，恢复页面正常显示。

这种“暖底 + 冷遮 + 旋转星球”的三层结构，在不使用 JS 动画帧的前提下实现了流畅的日夜切换效果。

SVG 图标结构说明

dark_mode.pug 中通过 <symbol> 定义了太阳与月亮两个 SVG 图标，使用 <use> 引用。这是 SVG Sprites 的常见实践：

  • viewBox：定义绘制坐标系（0 0 宽 高），1024 × 1024 是图标库的常用标准；

  • <symbol>：隐藏的容器，不会直接渲染，通过 <use> 实例化；

  • <use xlink:href="#icon-moon">：在任意位置引用符号，浏览器一次性解析 SVG 后仅缓存一份 path 数据，xlink:href 动态切换即可替换图标。

太阳图标由三层组成：黄色主体（太阳本身）、白色过渡（高光圆盘）、深色轮廓（内外描边），共同形成饱满的拟物风格。月亮图标通过非对称圆弧和轨道线条模拟新月效果。

Butterfly 版本 API 对照

btf 对象是 Butterfly 主题提供给前端脚本的全局工具集。不同版本之间 API 名称和调用方式有所差异：

功能 Butterfly 4.x Butterfly 5.x (当前) 说明
切换夜间模式 switchDarkMode() btf.activateDarkMode() 5.x 将主题方法统一收归到 btf 对象
恢复模式 switchLightMode() btf.activateLightMode() 同上
本地存储 - btf.saveToLocal.set('theme', val, 2) 5.x 封装了带过期时间的存储
消息提示 - btf.snackbarShow() 用于显示“已切换为夜间模式”的提示条
暗色类名 body.dark-theme body.DarkMode 类名改变，注意 CSS 和 JS 一致性

升级 Butterfly 时务必核对 btf 的 API 签名，避免因函数未定义导致切换失败。

实践中的问题与解决方案

1. 页面加载时出现主题闪烁（FOUC）

  • 现象：每次刷新页面，先出现浅色主题，再瞬间变成深色主题。

  • 根因：dark_mode.js 放在页面底部，执行时机晚于首次渲染；或 data-theme 未在 HTML 渲染前设置。

  • 解决步骤：

    1. 在 head.pug 中增加一段内联脚本，在页面解析前读取 localStorage 并设置 data-theme；
    2. 确保该内联脚本阻塞执行，位于所有 CSS 加载之前；
    3. 避免在 body 上先渲染默认主题再切换。

2. 切换按钮图标不更新

  • 现象：点击切换后页面颜色变了，但图标仍是月亮或太阳。

  • 根因：modeicon 的 xlink:href 未正确切换，或 SVG use 元素被缓存；也可能是新旧版本 Butterfly 的 btf API 不一致。

  • 解决步骤：

    1. 检查 switchNightMode() 中是否同时更新了 xlink:href；
    2. 为 use 元素添加唯一 id 并通过 JS 强制刷新；
    3. 核对当前 Butterfly 版本对应的 btf.activateDarkMode / btf.saveToLocal API。

3. 评论系统主题与页面不同步

  • 现象：页面切换为夜间模式后，utterances / Disqus / giscus 评论区仍为浅色。

  • 根因：第三方评论 iframe 独立加载，不会自动感知父页面 CSS 变量变化。

  • 解决步骤：

    1. 在 switchNightMode() 中调用对应评论组件的主题更新函数（如 utterancesTheme()、disqusReset()）；
    2. 对 giscus 可通过 postMessage 发送 setTheme 消息；
    3. 若组件不支持动态切换，可刷新 iframe 或重新加载评论脚本。

4. localStorage 被清理导致主题重置

  • 现象：隔一段时间或清理浏览器数据后，主题恢复为默认浅色。

  • 根因：主题状态依赖 localStorage，而浏览器清理、隐私模式或用户手动清除会丢失该数据。

  • 解决步骤：

    1. 在服务端渲染时通过 prefers-color-scheme 检测系统主题作为兜底；
    2. 提供“跟随系统”选项，减少对 localStorage 的依赖；
    3. 将用户偏好同步到后端（如登录用户保存到数据库）。

5. 版本升级后切换失效

  • 现象：升级 Hexo 或 Butterfly 后，夜间模式按钮点击无反应，控制台报错。

  • 根因：新版主题可能重命名了 btf 函数、调整了 data-theme 取值或改变了 CSS 变量名。

  • 解决步骤：

    1. 查阅目标版本 Butterfly 的更新日志，确认 btf API 变更；
    2. 使用新版推荐的 activateDarkMode / activateLightMode 方法；
    3. 在 dark_mode.styl 中核对 --card-bg、--font-color 等变量是否仍存在。
